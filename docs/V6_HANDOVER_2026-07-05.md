## V6 Features Added

- Post-decision external text output:
  - `External_Message`
  - `Analyst_Message`
  - `EPS_Message`
  - `Event_Message`
- Exchange-aware benchmark handling:
  - US default benchmark: `SPY`
  - US optional benchmark: `--us-benchmark QQQ`
  - NSE / `.NS` benchmark: `^NSEI`
- Liquidity audit and confirmation gate:
  - `Avg_Dollar_Volume_50D`
  - `Min_Avg_Dollar_Volume_50D`
  - `Liquidity_Status`
- Low liquidity is a confirmation blocker. It can downgrade an otherwise strong setup from `MOMENTUM_ACTIVE` to `MOMENTUM_PRESENT_WAIT_CONFIRMATION`.

## Output Contract

The primary user-facing decision remains:

- `Final_Decision`

Allowed values:

- `MOMENTUM_ACTIVE`
- `MOMENTUM_PRESENT_WAIT_CONFIRMATION`
- `REJECT`

External analyst/EPS/event text is context only. It is extracted after `Final_Decision` is already calculated and must not affect score, gates, ranks, or the final decision.
